How to be a Morse agent

  1. Morse code is beeps. A short one is a dot. A long one is a dash. Each letter has its own tune.
  2. Learn it by ear. Don't count the dots. Listen to the tune, like a song.
  3. New here? Start with Boot Camp. It teaches dots, dashes and the key in about two minutes.
  4. Every mission adds a letter. Get 9 out of 10 right to unlock the next one.
  5. The key: tap it quick for a dot. Hold it for a dash. Stop, and the letter is sent.
  6. The lever on HQ makes it easier or harder. Rookie gives big gaps and lots of help.
