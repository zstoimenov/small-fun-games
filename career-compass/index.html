For grown-ups

The compass uses Holland's six interest types (RIASEC), the model most careers advisers use, in kid words. It keeps four signals apart, because choosing to play something is not the same as being good at it:

  • Quiz: would-you-rather picks, out of 4 per style.
  • Likes: the kid's own 👍 😐 👎 on each game.
  • Plays: times a game was started from the Game Box home page.
  • Stars: share of stars won, in games that have stars.

The needle only uses Quiz, Likes and Plays. Stars sit beside it as "doing well". At 8, interests change often: use this to start a chat, never to decide anything.

Each game counts towards one or two styles. Only a few games build Creator and Helper skills so far, so the quiz and ratings matter most there. Everything stays on this device.
