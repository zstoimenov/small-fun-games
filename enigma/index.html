How to send a secret

  1. Pick a secret start. Use the arrows to spin the 3 rings to any 3 letters. Or press the dice button.
  2. Type your message. Every letter you press lights up a different letter. Those are your code letters.
  3. Send the code and the 3 start letters to a friend.
  4. Your friend sets the same start and types the code. Out pops your message!

Try it yourself: type a word, press Reset rotors, then type the code. Your word comes back! A letter never turns into itself.
