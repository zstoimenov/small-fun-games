How to send a secret

  1. Pick a secret start. Spin the 3 rings with the arrows, or tap New start.
  2. Type your message. Each letter lights up a different one. Those are your code.
  3. Tap Share to send the code to a friend.
  4. Tell them the 3 start letters a different way - say them out loud! Without them, nobody can read it.
  5. Your friend sets the same start and types the code. Out pops your message!

Try it: type a word, tap Reset, then type the code. Your word comes back! Tap the code line to see both.
